## MongoDB Operators Used

| Operator | Meaning | Example |
|----------|---------|---------|
| $eq | Equal to | marks: {$eq:88} |
| $gt | Greater than | marks: {$gt:85} |
| $lt | Less than | marks: {$lt:60} |
| $gte | Greater than or equal to | marks: {$gte:90} |
| $lte | Less than or equal to | marks: {$lte:70} |
| $and | All conditions must be true | $and:[...] |
| $or | At least one condition must be true | $or:[...] |

## Conclusion

This project provided practical knowledge of NoSQL databases using MongoDB. A Student Management System containing 50 student records was created, and different MongoDB operations were performed on the data.

Through this project, I learned how to insert, retrieve, update, and delete documents. I also learned how to sort data in ascending and descending order, use comparison operators such as $eq, $gt, $lt, $gte, and $lte, and apply logical operators such as $and and $or.

Overall, this project helped me understand how MongoDB can be used to manage and query student data efficiently.
